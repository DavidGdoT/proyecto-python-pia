## ¿Qué hace este proyecto? 
Despliega un menú con diferentes opciónes, dejando al usuario elegir las monedas que quiera para sacar su conversión a otras monendas de todos los paises y con la posibilidad de generar graficas para tener una comparación visual de la diferencia en cuanto valor



## API utilizada Nombre de la API y link 
Exchangerate - https://v6.exchangerate-api.com/v6/b6d737f0e4b316d91afd4e28/latest/USD

## ¿Cómo ejecutarlo? 

1. Instalar dependencias: pip install requests matplotlib 
2. Ejecutar: python main.py 

## Gráficas generadas 
La primera grafica la comparación de todas las monedas elegidas por el usuario
La segunda gráfica muestra las primeras monedas de mayor a menor según la cantidad a mostrar que eliga el usuario
la tercera gráfica muestra las primeras monedas de menor a mayor según la cantidad a mostrar que eliga el usuario
